# 🔎 Lost & Found

### Report. Search. Recover.

Lost & Found is a web-based platform that helps people report lost belongings, search for found items, and reconnect items with their owners.

## 📌 About

Lost & Found aims to make recovering lost belongings easier and more organized. Users can report lost or found items, search listings, and manage their reports through a web interface.

## ✨ Features

- Report Lost Items
- Report Found Items
- Search for Lost and Found Items
- User Registration and Login
- Manage Personal Reports
- Admin Panel for Managing the Platform

## 🛠️ Technologies Used

- PHP
- HTML
- CSS
- JavaScript
- Vite
- MySQL (if configured in the project)

## 🚀 Installation

**1. Clone the repository**

```bash
git clone https://github.com/mortazaefti/Lost-Found.git
```

**2. Navigate to the project directory**

```bash
cd Lost-Found
```

**3. Install dependencies**

If Node.js and npm are required by the project, run:

```bash
npm install
```

**4. Run the project**

Set up the project in a compatible local PHP environment, such as XAMPP, and configure the required database settings.

If the project uses Vite, check `package.json` for the available development scripts.

## 🎯 Project Objectives

- Make reporting lost items easier.
- Help users find lost belongings.
- Connect people with their lost or found items.
- Provide a simple and user-friendly platform.
